# Security reporting

Please use GitHub's private vulnerability reporting feature for this repository if enabled. If it is unavailable, open an issue requesting a private contact without including exploit details, secrets or sensitive telemetry. Do not publish credentials or private lab evidence in a public issue.

Supported baseline: the current main branch with the versions specified in Compose. This is a controlled lab, not an internet-facing production service. See [security boundaries](docs/security.md). Dependency vulnerabilities should also be reported to the relevant upstream maintainer.
